# Outline Template — sections, with what good and bad look like

The outline is the contract with the author. Ten sections, this order. Canonical filled-in
example: `curriculum/module-07-outline.md`.

**Register: the outline is read by the author — write it the way they talk.** No shorthand
chains, no invented vocabulary. Module 10's first outline drew the spine as an abbreviation
chain — `FRESH/GUARD? → ENVIRONMENT?` — and was rejected: *"you are using too many complex
terms and words. keep it closer my tone of voice, and as if i was speaking to a friend. wtf
does that mean."* Write questions as actual questions ("How fresh does it need to be — and
what happens when it fails?"). House method terms (bookend, spine, capstone) stay inside
the skill; the outline describes the thing in ordinary words.

## 1. One-line pitch & the one idea

- **Pitch** = a client sentence: who it's for, what they can do after, in business terms.
  - ✅ *"Type a prospect brand's name, get back a researched, on-brand partnership one-pager — minutes and cents, not a designer afternoon."*
  - ❌ *"Learn the OpenAI API, structured outputs, and image generation."* (a syllabus, not a pitch)
- **One idea** = one mental model, one sentence, drawn as a spine. If it takes two sentences, it's two modules.
  - ✅ *"The factory line: the model fills two slots; research fills the model; code owns the rest."*
  - ❌ Anything with "and also" in it.

## 2. Components we teach, and why

One bullet per component: **the component — why it matters**, where "why" is a capability
someone pays for, tied to the arc.
- ✅ *"**Web search, in the API** — the USP must name real things about the prospect; search is how generation stops being confident fiction."*
- ❌ *"**crawl4ai** — a library for LLM-based extraction with schema support."* (describes the tool, not what it buys)

## 3. What they walk out with

Concrete artifact list: repo files by name, deployed/stored things with URLs, the mental
model. If an item can't be pointed at on a screen, it doesn't belong here.

## 4. The bookend

The finished deliverable as a real log/screenshot + an unexplained payoff line, and how the
close re-reads it. Include the counted mystery if one exists — and check the count survives
its own recount.

## 5. Part-by-part

Per part: the **gap** the previous part left (phrased as the next requirement, not a failure)
· concept content · BUILD with the 🤖 file it generates · ✅ checkpoint (room-verifiable) ·
any live failure moment (destined for speaker notes). Apply the teaching-loop rule: every
concept must show its build, its checkpoint, and its line in the capstone — or be cut.

## 6. Run of show

Timed table for the real duration (room of 15 ≈ 3× solo speed). Protected moments to the
minute. The sacrifice rule: what to cut when late, what never. Catch-up path (tagged `live/`)
and dry-run path (replayable without third parties).

## 7. Capstone

The whole spine, run by the student on *their* chosen subject. Nothing new introduced. State
the judgment question that makes the share-around land (*"would this survive the meeting?"*).

## 8. Prerequisites (48h before)

One copy-paste preflight command + a filled-in `.env` template. Flag anything with lead time
(account approvals, API access). Facilitator prep lines: dry-runs to perform, numbers to
measure, shortlists to prepare.

## 9. Gotchas to pre-empt out loud

Numbered, each with the scheduled moment to say it and real error text. These feed speaker
notes, not slides.

## 10. Aphorisms + doc set plan

3–5 one-liners, each provable live during the session. Close on two/three things to keep.
Doc-set split per the SKILL table (DECK/HANDOUT/GUIDE/ANATOMY/README/TROUBLESHOOTING/starter+live).

## Also state explicitly (anywhere it fits)

- **Inherited decisions** used verbatim from earlier modules, and **exports** later modules
  depend on ("M8's preflight deploys this service").
- **Deferred on purpose** list — what you're not teaching and which module owns it.
- **If you have a full day** — everything cut for time, by name. Never the author's
  commercial pricing: module 10's list carried the real proposal amount and it was cut same
  day (*"dont include the pricing. this is a teaching module."*).
